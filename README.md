# 며칠 버틸래?

낮에는 숲에서 자원을 모아 마을을 짓고, 밤에는 화톳불을 노리는 몬스터를 막아내는 생존 디펜스 게임입니다.
보스를 쓰러뜨리면 숲 너머 새 지역이 열립니다.

## 플레이

브라우저에서 바로 실행됩니다. 설치는 필요 없어요.

## 조작 (PC)

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| 1~0, Q/E | 건물 선택 |
| 클릭 | 건물 설치 |
| B | 가방 |
| R | 무기 스킬 |
| Z X C V | 보스 처치 능력 |
| F / 스페이스 | 낚아채기 |
| N | 밤 부르기 |
| P | 일시정지 |

폰에서는 화면을 끌어서 이동하고, 땅을 탭해서 건물을 지을 수 있어요.

## 저장

진행 상황은 매일 아침 브라우저에 자동 저장됩니다.
