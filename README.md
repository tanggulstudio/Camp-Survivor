# 캠프 서바이버 (Camp Survivor)

낮에는 숲에서 자원을 모아 마을을 짓고, 밤에는 화톳불을 노리는 몬스터를 막아내는 생존 디펜스 게임입니다.
보스를 쓰러뜨리면 숲 너머 새 지역이 열립니다.

## 플레이

브라우저에서 바로 실행됩니다. 설치는 필요 없어요.

## 조작 (PC)

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| B | 건설 창 (벽·포탑·생산·관리) |
| 1~9, Q/E | 건물 선택 · 분류 넘기기 |
| 클릭 | 건물 설치 |
| I | 가방 |
| R | 무기 스킬 |
| Z X C V G | 보스 처치 능력 |
| F / 스페이스 | NPC 대화 · 낚아채기 |
| N | 밤 부르기 |
| M | 지도 |
| P | 일시정지 |
| ESC | 열린 창 닫기 |

폰에서는 화면을 끌어서 이동하고, 땅을 탭해서 건물을 지을 수 있어요.

## 펫

보스를 잡으면 늑대, 치유 두꺼비, 수정 정령, 꼬마 임프를 얻어요. 가방(I) → 펫 탭에서 하나를 데리고 다니면 함께 싸우며 Lv30까지 자라요.

## 저장

진행 상황은 매일 아침 브라우저에 자동 저장됩니다.
