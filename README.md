# 캠프 서바이버 (Camp Survivor)

낮에는 숲에서 자원을 모아 마을을 짓고, 밤에는 화톳불을 노리는 몬스터를 막아내는 생존 디펜스 게임입니다.
보스를 쓰러뜨리면 숲 너머 새 지역이 열립니다.

## 플레이

브라우저에서 바로 실행됩니다. 설치는 필요 없어요.

## 조작 (PC)

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| B | 건설 창 (벽·포탑·생산·관리) |
| 1~9, Q/E | 건물 선택 · 분류 넘기기 |
| 클릭 | 건물 설치 |
| I | 가방 |
| R | 무기 스킬 |
| Z / 스페이스 | 보스 유물 능력 |
| F | NPC·부화기·둥지·보관함 상호작용 · 낚아채기 |
| N | 밤 부르기 |
| M | 지도 |
| P | 일시정지 |
| ESC | 열린 창 닫기 |

폰에서는 화면을 끌어서 이동하고, 땅을 탭해서 건물을 지을 수 있어요.

## 펫

지역마다 둥지에 알이 생기고, 몬스터와 보스도 알을 떨어뜨려요. 마을에 부화기를 지어 알을 넣으면 2일 뒤 펫이 태어나요.

## 도전의 탑 · 고대 보물고

마을의 도전의 탑에서 무한 층을 오르며 증표를 모아 영구 강화를 살 수 있어요. 고대 열쇠 조각 5개를 모으면 서리 설원의 고대 보물고에서 고유 장비를 얻을 수 있어요.

## 저장

진행 상황은 매일 아침 브라우저에 자동 저장됩니다.
