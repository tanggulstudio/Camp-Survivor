# 캠프 서바이버 (Camp Survivor)

낮에는 숲에서 자원을 모아 마을을 짓고, 밤에는 화톳불을 노리는 몬스터를 막아내는 생존 디펜스 게임입니다.
보스를 쓰러뜨리면 숲 너머 새 지역이 열립니다.

## 플레이

브라우저에서 바로 실행됩니다. 설치는 필요 없어요.

## 조작 (PC)

| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| B | 건설 창 (벽·포탑·생산·관리) |
| 1~9, Q/E | 건물 선택 · 분류 넘기기 |
| 클릭 | 건물 설치 |
| I | 가방 |
| R | 무기 스킬 |
| Z / 스페이스 | 보스 유물 능력 |
| F | NPC·부화기·둥지·보관함 상호작용 · 낚아채기 |
| N | 밤 부르기 |
| M | 지도 |
| P | 일시정지 |
| ESC | 열린 창 닫기 |

폰에서는 화면을 끌어서 이동하고, 땅을 탭해서 건물을 지을 수 있어요.

## 펫

지역마다 둥지에 알이 생기고, 몬스터와 보스도 알을 떨어뜨려요. 마을에 부화기를 지어 알을 넣으면 2일 뒤 펫이 태어나요.

## 도전의 탑 · 고대 보물고

마을의 도전의 탑에서 무한 층을 오르며 증표를 모아 영구 강화를 살 수 있어요. 고대 열쇠 조각 5개를 모으면 서리 설원의 고대 보물고에서 고유 장비를 얻을 수 있어요.

## 오래 즐기기

- 숙련도 8종(채광·벌목·근접·원거리·마법·낚시·요리·건설), 최대 Lv50
- 보스 소환물: 지역 몬스터 재료로 만들어 둥지에 바쳐야 보스가 깨어나요
- 몬스터 도감과 여관의 매일 의뢰 3개

## 친구와 함께하기

최대 4명이 한 캠프에서 플레이해요. 호스트가 게임 중에 일시정지 → "친구와 함께하기" → 방 만들기로 6자리 코드를 만들고, 친구는 시작 화면에서 코드로 참가해요. 자원·건물·밤은 함께, 장비·가방·숙련도는 각자예요. (GitHub 사이트에서 동작해요)

## 난이도

새로 시작할 때 쉬움·보통·어려움 중에서 골라요.

## 저장

진행 상황은 매일 아침 브라우저에 자동 저장됩니다.

## 코드 구조

게임은 이미지 파일 없이 Canvas 코드로 그려요. `index.html`에는 화면 틀(HTML·CSS)만 있고, 게임 코드는 `js/` 폴더에 나뉘어 있어요. 아래 순서대로 불러오며, 앞 파일에 있는 이름을 뒤 파일에서 그대로 써요.

| 파일 | 내용 |
|---|---|
| `js/zh.js` | 중국어(간체) 번역표. `ZH_KO`는 한국어 원문, `ZH_EN`은 `_L()`의 영어 문장(`{0}` 자리에 실행 중 값이 들어감)을 키로 씀 |
| `js/i18n.js` | 언어 선택(한국어/English/简体中文)과 영어 번역표(EN), 언어 메뉴 |
| `js/data.js` | 맵 크기, 건물(B), 몬스터(ET), 장비(ITEMS), 요리(RECIPES), 작물, 생물군집 등 데이터 |
| `js/art.js` | 모든 그림 함수(`draw…`, `bake…`), 몬스터 그림(DRAW2), 건물·캐릭터 그림. 게임 규칙은 없음 |
| `js/world.js` | 새 게임 상태, 불씨 제단, 월드 생성(강·절벽·랜드마크·던전) |
| `js/engine.js` | 몬스터 길찾기(flow field), 공용 도우미, 낮/밤 |
| `js/combat.js` | 공격·피해·드롭·보스·소환 |
| `js/net.js` | 친구와 함께하기(P2P) |
| `js/input.js` | 채집, 키보드·터치 조작, 건설 바 |
| `js/update.js` | 매 프레임 게임 진행 |
| `js/steamnet.js` | Steam판 '친구와 함께하기': Steam 로비·초대로 같은 호스트/참가자 메시지를 주고받음 (웹판은 PeerJS 그대로) |
| `js/rounds.js` | 오늘 밤 습격 계획과 길목 깃발, 새벽 보고서, 화톳불이 꺼지는 장면, 결과 카드 |
| `js/ui.js` | 상단 정보, 카드, 저장/불러오기, 메인 루프, 설정, 게임패드 |

규칙
- 각 파일은 맨 위에서 바로 실행되는 코드가 **뒤 파일**의 함수나 값을 쓰면 안 돼요(불러오는 순서 때문). 함수 안에서 쓰는 건 괜찮아요.
- 저장 키 `mbr-save-v1`과 저장 데이터 구조는 바꾸지 않아요.
- 화면에 보이는 새 문구는 `_T()`/`_L()`로 감싸고 `js/zh.js`에도 중국어를 넣어요. 빠지면 중국어판에서 영어로 보여요.
- 화면에 보이는 새 문구는 `_T()`/`_L()`로 감싸고, `js/zh.js`에도 중국어를 넣어요. 빠지면 중국어판에서 영어로 보여요.
- 데스크톱판(`desktop/prepare.js`)은 `index.html`과 `js/` 폴더를 함께 복사해요.
- 주소 끝에 `?test`를 붙이면 일시정지 창에 "다음 지역으로 (테스트)" 버튼이 생겨요.

## 디펜스판 (`/defense/`)

기존 게임(루트)은 그대로 두고, 디펜스판은 `defense/` 폴더에 따로 있어요. 주소: `https://tanggulstudio.github.io/Camp-Survivor/defense/`

- 저장 키가 달라요(`csd-save-v1`, `csd-meta-v1`, `csd-mp-char-v1`). 두 버전이 서로 세이브를 덮어쓰지 않아요.
- `defense/js/defense.js`: 채집 없는 맵, 금화 하나로 통일한 경제, 라운드(5라운드마다 보스, 10라운드부터 각성 보스), 100라운드 승리 후 무한, 도전 규칙은 첫 클리어 후 해금, 상자 보상, 도전의 탑(혼자면 바깥 시간 정지, 멀티 호스트면 흐름).
- `defense/js/classes.js`: 직업 13종 + 히든 4종, 액티브 4·패시브 4(Lv1·Lv5·2차·3차에 해금, 전직마다 강화), 히든 피스, 직업 무기 강화·합성, 직업 창(K), 마을 상점(잡화점·보석상·여관·태양의 제단) 디펜스용 개편.
- `defense/js/nights.js`: 라운드마다 강화 3택1, 밤의 규칙(질주·중갑·떼거리·분열·재생·포위·정예·박쥐), 밤의 할 일(금화 도둑·소환 토템·버프 구슬), 밤 2배속.
- 세 파일은 `rounds.js` 뒤, `ui.js` 앞에 로드돼 기존 함수를 덮어써요. 기존 생활 코드는 그대로 남아 있어요.
- 아직 Steam 빌드와 함께하기(멀티)에는 연결하지 않았어요.
